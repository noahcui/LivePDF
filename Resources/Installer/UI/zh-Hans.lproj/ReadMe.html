LivePDF

PDF 文件更新后自动重载，并保留页码、页内位置、缩放和显示模式。适用于使用 latexmk 等工具反复生成 PDF 的论文写作流程。

系统要求

  • Apple Silicon Mac（arm64），macOS 14 或更新版本。
  • 无需安装 Swift、Xcode、Command Line Tools 或 TeX。
  • 安装需要管理员授权，只能安装到当前启动系统盘。

安装内容

  • 应用：/Applications/LivePDF.app
  • 命令行入口：/usr/local/bin/livepdf

本项目源码、文档和原创图标使用 MIT 许可证，许可声明随 app 提供。当前安装包未使用 Developer ID 证书签名或 Apple 公证。

开始使用

安装完成后，从“应用程序”打开 LivePDF，按 ⌘O 打开 PDF，或将 PDF 拖入窗口。首次启动后，也可在 Finder 的“打开方式”中选择 LivePDF。

livepdf paper.pdf
livepdf "有 空格的论文.pdf" another.pdf

支持相对路径、空格和多个文件；每个 PDF 使用独立窗口。若终端提示找不到命令，可直接使用 /usr/local/bin/livepdf，或把 /usr/local/bin 加入 PATH。

⌘R 手动重载，⌘F 搜索，⌘L 跳页，⌘+ / ⌘- 缩放，⌘0 实际大小，⌘9 适应宽度。默认在文件停止变化约 300 ms 后自动重载；新内容无效或尚未写完时保留旧文档。

应用和安装器会按系统首选语言显示简体中文或英文。安装过程不会自动启动 app，也不会修改 shell 配置。
