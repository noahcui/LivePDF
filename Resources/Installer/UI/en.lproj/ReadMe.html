LivePDF

LivePDF automatically reloads a PDF when the file changes, preserving the page, reading position, zoom, and display mode. It works well with writing workflows that repeatedly generate a PDF using tools such as latexmk.

System requirements

  • An Apple Silicon Mac (arm64) running macOS 14 or later.
  • No Swift, Xcode, Command Line Tools, or TeX installation is required.
  • Installation requires administrator authorization and uses the current startup volume.

Installed files

  • Application: /Applications/LivePDF.app
  • Command: /usr/local/bin/livepdf

The source code, documentation, and original icon use the MIT license. License notices are included in the app. This installer is not signed with a Developer ID certificate or notarized by Apple.

Getting started

After installation, open LivePDF from Applications. Press ⌘O to open a PDF or drag one into the window. After the first launch, you can also select LivePDF in Finder’s Open With menu.

livepdf paper.pdf
livepdf "paper with spaces.pdf" another.pdf

Relative paths, spaces, and multiple files are supported. Each PDF opens in its own window. If your terminal cannot find the command, use /usr/local/bin/livepdf directly or add /usr/local/bin to PATH.

Use ⌘R to reload, ⌘F to search, ⌘L to go to a page, ⌘+ / ⌘- to zoom, ⌘0 for actual size, and ⌘9 to fit the width. By default, automatic reload waits about 300 ms after the last file change. An invalid or incomplete replacement leaves the previous document visible.

The app and installer follow your preferred system language, with Simplified Chinese and English available. Installation does not launch the app or change your shell configuration.
