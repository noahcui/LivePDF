LivePDF

LivePDF 1.1.0 reads PDF and Markdown files and automatically reloads them after changes. PDF windows preserve the page, reading position, zoom, and display mode. Markdown previews keep their zoom and preserve the reading position when possible.

System requirements

  • An Apple Silicon Mac (arm64) running macOS 14 or later.
  • No Swift, Xcode, Command Line Tools, or TeX installation is required.
  • Installation requires administrator authorization and uses the current startup volume.

Installed files

  • Application: /Applications/LivePDF.app
  • Command: /usr/local/bin/livepdf

The source code, documentation, and original icon use the MIT license. License notices are included in the app. The app has an ad-hoc integrity signature; this installer is not signed with a Developer ID certificate or notarized by Apple.

Getting started

After installation, open LivePDF from Applications. Press ⌘O to open a PDF or Markdown file, or drag one into the window. After the first launch, you can also select LivePDF in Finder’s Open With menu.

livepdf paper.pdf
livepdf "notes with spaces.md" paper.pdf

Relative paths, spaces, and multiple files are supported. Each document opens in its own window. If your terminal cannot find the command, use /usr/local/bin/livepdf directly or add /usr/local/bin to PATH.

Use ⌘R to reload, ⌘F to search, ⌘G / ⇧⌘G to move between matches, and ⌘+ / ⌘- to zoom. In PDF windows, ⌘L goes to a page, ⌘0 shows actual size, and ⌘9 fits the width. By default, automatic reload waits about 300 ms after the last file change. An invalid or incomplete replacement leaves the previous document visible.

Markdown preview

Open a UTF-8 .md, .markdown, .mdown, or .mkd file. Edit it in your usual editor or click Open in TextEdit, then save to update the preview. Headings, emphasis, code, lists, task lists, quotes, tables, links, and local images are supported. Relative Markdown and PDF links within the document’s folder open in LivePDF.

The renderer supports an offline Markdown subset. Raw HTML is shown as text; scripts, remote images, math rendering, and Mermaid diagrams are not supported. Images must be in the document’s folder or its subfolders. Image changes appear when the Markdown is reloaded; changing an image alone does not trigger a reload.

The app and installer follow your preferred system language, with Simplified Chinese and English available. Installation does not launch the app or change your shell configuration.
